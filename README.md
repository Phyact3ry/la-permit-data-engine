# LA Permit Data Engine

Data pipeline for LA County construction contractors. It pulls contractor licenses (CSLB),
building permits and inspection records from LA City open data, ties permits back to the
contractors that filed them, scores each contractor for sales fit, and runs SMS/voice outreach
off the result. A small Cloudflare Worker serves the data as JSON.

I ran it against the full datasets: about 23k contractors, ~550k permits and ~11M inspection
rows. Roughly 92% of permits matched to a contractor.

## Stack

Node + TypeScript, run with `tsx` (no build step). Postgres on Supabase with Drizzle for the
schema and queries. Inngest runs the scheduled/background jobs. The API is Hono on a Cloudflare
Worker, with a D1 table used as an address -> contractor lookup cache. Permit classification and
outreach copy use Claude (Haiku and Sonnet).

## What the pipelines do

- `ingest-cslb` - scrapes the CSLB license site
- `ingest-lacity-permits` - permits from Socrata, then Haiku tags each `work_description` with a project type (ADU, kitchen, ground-up, etc.)
- `ingest-lacity-inspections` - inspection history
- `link-permits-to-contractors` - matches permits to contractors by normalized address + license number, caches the result in D1
- `compute-icp-scores` - scores each contractor across 6 dimensions, assigns an A-D tier and stores the signals behind it (permit velocity, ADU activity, multi-city, license expiry...)
- `generate-hypotheses` - Sonnet writes 2-3 outreach angles per contractor from those signals
- `compute-inspection-stats` - first-time inspection pass rates per type, published as a JSON snapshot through the Worker

Schedules and manual trigger events are defined on each function in `src/inngest/`.

## Running it

```
npm install
cp .env.example .env      # fill these in
npx drizzle-kit migrate
npm run dev:serve         # Inngest server on :3000
npm run dev:inngest       # Dev UI on :8288
```

Then trigger functions manually from the Dev UI.

## Schema

8 tables in `src/schema.ts`: contractors_enriched, enrichment_signals, hypotheses,
outreach_sequences, outreach_touches, pipeline_state, permits, inspections. Migrations are in
`drizzle/` and generated by drizzle-kit, so don't edit them by hand.
